# Demonstration script

Start with `./start.ps1` on Windows or `python start.py`; open `http://localhost:3000`.

1. **Baseline:** show the 24-country trial and synthetic evidence notice. This is a planning simulation, not verified legal research.
2. **Evidence:** open Germany, select a rule, then follow the permit-to-delivery timeline.
3. **Regulatory change:** analyze the Japanese field event. Explain the shared design's rework and resulting risk. Create the separate-label repair and approve with reviewer attribution.
4. **Weather:** analyze Boston–Frankfurt disruption. Inspect the Amsterdam route alternative, cost and delivery trade-offs. A proposed route requires approval before use in the current plan.
5. **Explanation:** select the proposal in Planner assistant and ask why the country is at risk. Answers cite stored evidence and mark simulations.
6. **Governance:** inspect the audit trail and export the approved calendar. Repeated exports of a scenario retain event IDs.
7. **Replacement:** preview and commit `data/demo/replacement.json` in Data & research. Its different product, countries, languages, dates, routes and changes work without source edits.

Canada's permit-delay event is the backup demonstration. Reset demo data restores the packaged footprint. No external API, Chalk, Photon, Docker or cloud hosting is necessary.
